# AI in research

This section is about using generative AI for lab work, from analysis code to papers and reviews. It covers chat assistants such as Copilot, ChatGPT and Claude, and coding agents such as Claude Code and Codex, which edit files and run commands for you.

!!! abstract "The short version"
    - **KU Leuven:** confidential data, which include participant data, unpublished work and PDFs of papers, only go into Copilot with your KU Leuven login. AI that acts on its own is not allowed. You are responsible for what you use, and you say how you used it.
    - **The lab:** we keep participant data out of AI tools, use coding agents only with approval and without data, test AI-written analysis code on simulated data, and write papers and theses in our own words.
